## 阅读顺序

1. 先看 PRD 的「一页纸摘要」和「功能需求」，确认范围。
2. 再看领域模型的「聚合与实体」「权限模型」，确认概念与边界。
3. 最后看模块骨架的「目录结构」「模块职责」「API 设计」，进入实现。

## 当前状态

本目录仅包含设计文档，不包含实现代码。模块目录、接口契约和实现顺序见 [模块骨架](./design/module-skeleton.md) 第 2、4、10 节。
